# 关键决策

## 001 - 本地附件与 SQLite

业务元数据存在 SQLite，文件存服务器持久目录；备份使用 SQLite `VACUUM INTO` 快照并打包附件。

## 002 - 应用内定时发布

单 worker 启动时补扫并每分钟扫描一次到期文章。数据库计划发布时间为权威；不引入 Redis/Celery。

## 003 - 在线恢复通过 CLI

恢复涉及替换 SQLite 与附件目录；网页将服务置于维护状态后执行，CLI 恢复则要求服务停止。两种方式都会先生成当前数据的回滚备份。

## 004 - 首次密码

默认开发账户 `admin/1234` 强制改密。生产部署可通过 `INITIAL_ADMIN_PASSWORD` 首次设置；安装后不会重置账户。

## 005 - 操作审计

在 SQLite 中持久保存用户、文章、评论和备份/恢复关键变更；不记录密码、正文或会话令牌。

## 006 - 富文本正文与 Markdown 兼容

新文章由富文本编辑器保存为经过服务端清理的 HTML；既有文章保持 Markdown 格式并在编辑时渲染到富文本编辑器。`articles.body_format` 区分两种格式，附件仍通过授权接口访问，正文图片/视频使用受控附件 URL。

## 007 - 独立图集

图集与文章独立建模。图集图片保存在附件目录，元数据单独记录；图集可设置指定用户或用户组，图片接口逐次校验图集读取权限。浏览器支持多选图片和目录上传，不要求读者打开文章。

## 008 - 定时文章邮件通知

定时文章发布后，向文章的有效读者（全员可见文章为所有启用用户；指定可见文章为指定用户与用户组成员）发送邮件。用户在个人设置维护邮箱；管理员在系统设置页面配置 SMTP。SMTP 密码使用 `APP_SECRET` 派生的 Fernet 密钥加密后存入 SQLite，界面不回显密码。未启用 SMTP 时不发送邮件，发布不受影响。通知不包含正文内容。

## 009 - Server酱微信通知

采用 Server酱 Turbo（SCT SendKey）向微信推送，不使用个人微信协议。SendKey 由每位用户在个人设置配置并用 `APP_SECRET` 派生的 Fernet 密钥加密存入用户记录；定时文章发布时只向该文有效读者各自的 SendKey 推送。Server酱 API 密钥不会回显或写入日志；API 请求失败只记录脱敏状态。管理员的 SMTP 仍为可选邮件渠道。

## 010 - 126 邮箱 SMTP 填写说明

管理员 SMTP 设置以 126 免费邮为默认：`smtp.126.com`，默认 SSL/465；认证使用完整的 `@126.com` 邮箱账号和网易客户端授权密码。587 作为 465 连通性问题时的备选，取消 SSL 后使用 STARTTLS。页面逐字段链接/备注网易官方帮助说明。
